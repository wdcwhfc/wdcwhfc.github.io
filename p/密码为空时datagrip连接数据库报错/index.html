密码为空时，DataGrip连接数据库报错

Jan 22, 2026
1 minute read

⚠️ 不太理解的神经问题

在使用DataGrip连接数据库时，如果密码为空而你又以常规且正常的方式留空密码字段进行配置，连接会报错：

原因在于，你需要在密码字段输入框上右键，点击 Set Empty，然后 DataGrip 才会理解密码为空而不是你忘输入了或者什么其他情况。

尽管直接留空和点击 Set Empty 在输入表单显示表现上完全一致。

大概是有什么考虑，但是还是很神经 (¯―¯٥)
