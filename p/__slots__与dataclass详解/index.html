__slots__与dataclass详解

Jul 16, 2026
2 minute read

‼️ By Gemini

在 Python 中，__slots__ 和 dataclass 是两个用于优化和简化类定义的重要工具。

  • __slots__：用于性能优化（减少内存占用、提高属性访问速度）。
  • dataclass：用于代码简化（自动生成常见的模板代码，如构造函数、表示方法等）。

__slots__：内存与性能优化利器

为什么需要 __slots__？

在 Python 中，默认情况下每个类实例都会有一个名为 __dict__ 的字典来存储它的属性。字典为了保证 $O(1)$ 的查询效率，底层使用了哈希表，这会带来相当大的内存开销。 如果你需要创建成千上万个小对象（例如三维坐标点、游戏中的大量粒子），这些 __dict__ 字典会吃掉极大的内存。

__slots__ 的作用

通过在类中定义 __slots__ 变量（通常是一个元组），你可以显式地声明：“这个类只允许拥有这些属性”。 Python 就会放弃为每个实例创建 __dict__ 字典，转而使用一种结构更紧凑的、基于指针数组的内部结构来存储属性。

class PointWithSlots:
    # 显式声明该类只有 x 和 y 两个属性
    __slots__ = ('x', 'y')

    def __init__(self, x, y):
        self.x = x
        self.y = y

# 1. 正常创建和访问
p = PointWithSlots(10, 20)
print(p.x, p.y)  # 输出: 10 20

# 2. 无法动态添加未声明的属性
try:
    p.z = 30  # 尝试添加 z 属性
except AttributeError as e:
    print(f"错误: {e}")  # 输出: 错误: 'PointWithSlots' object has no attribute 'z'

# 3. 验证没有 __dict__
print(hasattr(p, '__dict__'))  # 输出: False

💡 __slots__ 的注意事项

  1. 无法动态添加属性：由于没有了 __dict__，你不能给实例绑定 __slots__ 以外的新属性。
  2. 继承问题：子类默认不会继承父类的 __slots__（子类依然会有 __dict__）。如果希望子类也优化内存，子类也必须声明 __slots__（可以为空元组 ()）。
  3. 不能简单地与多继承混用：多个拥有非空 __slots__ 的父类无法直接被同一个子类继承。

dataclass：告别冗长的模板代码

什么是 dataclass？

dataclass（数据类）自 Python 3.7 引入，是一个装饰器。它的核心目的是减少样板代码（Boilerplate Code）。 在写一个主要用于“存储数据”的类时，你通常需要写 __init__、__repr__、__eq__ 等方法。dataclass 可以根据你声明的类型提示（Type Hints），自动帮你生成这些方法。

from dataclasses import dataclass, field

@dataclass
class User:
    username: str                  # 必须提供的属性
    email: str
    is_active: bool = True         # 带默认值的属性
    # 对于列表、字典等可变对象，必须使用 default_factory
    roles: list[str] = field(default_factory=list) 

# 1. 自动生成 __init__ 构造函数
user1 = User("alice", "alice@example.com")
user2 = User("alice", "alice@example.com")

# 2. 自动生成美观的 __repr__
print(user1)  
# 输出: User(username='alice', email='alice@example.com', is_active=True, roles=[])

# 3. 自动生成 __eq__ (比较内容而非内存地址)
print(user1 == user2)  # 输出: True

常用参数控制

@dataclass 装饰器接收多个配置参数，常用的有：

  • frozen=True：将类变为“只读”（不可变对象），并自动生成 __hash__ 方法，使其可以作为字典的键。
  • order=True：自动生成 __lt__、__le__、__gt__、__ge__ 方法，让对象可以进行大小比较和排序。

两者结合：dataclass 支持 __slots__ 吗？

支持！ 在 Python 3.10 及以上版本中，@dataclass 提供了一个非常方便的参数 slots=True。它会自动为你生成的类加上 __slots__，让你同时享受 dataclass 的便捷编写和 __slots__ 的高性能、省内存。

from dataclasses import dataclass

@dataclass(slots=True)
class OptimizedPoint:
    x: float
    y: float

p = OptimizedPoint(1.5, 2.5)
# 此时既拥有自动生成的 __init__、__repr__，又没有 __dict__，极省内存！
print(hasattr(p, '__dict__'))  # 输出: False

总结：该用哪一个？

特性__slots__dataclass
核心目的减少内存占用，提升属性读写速度减少样板代码，提高开发效率
主要原理移除 __dict__ 字典，改用紧凑的指针数组自动生成 __init__ / __repr__ / __eq__ 等方法
适用场景需要创建成百万上千万个轻量级对象的场景任何用于存储和传输数据的类
动态属性默认禁止（无法在运行时添加新属性）默认允许（除非设置了 frozen=True 或结合了 slots）

💡 黄金法则：

  • 绝大多数情况下，优先使用 dataclass 来保持代码的干净、可读。
  • 当你的程序出现内存瓶颈，且瓶颈在于数以万计的实例对象时，使用 __slots__。
  • 在 Python 3.10+ 中，直接使用 @dataclass(slots=True) 可以完美兼得两者的优势。
